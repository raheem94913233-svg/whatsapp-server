# سيرفر واتساب — نظام الحضور الذكي

يرسل خطابات «لمن يهمه الأمر» (رسالة + ملف PDF) للمعلمين تلقائيًا في الوقت المحدد بصفحة واتساب،
ويرسل إشعارات غياب الطلاب لأولياء الأمور (حد أقصى قابل للتعديل، افتراضيًا 50 رسالة)،
والتقرير الشهري لكل معلم كملف Word، وإحصائية يومية لرقم المدير، ويوصل طلبات الاستئذان فورًا.

حماية من الحظر: فاصل زمني بين كل رسالة وأخرى (افتراضيًا 5 ثوانٍ)، وأول رسالة لأي رقم تنتهي بطلب الرد بكلمة «تم».

## النشر على Render (الخطة المجانية تكفي — لا يلزم Disk)
1. ارفع ملفات هذا المجلد (كما هي) إلى مستودع GitHub جديد.
2. افتح https://dashboard.render.com › **New** › **Blueprint** واختر المستودع، ثم **Apply**
   (أو: New › Web Service › اختر المستودع › Instance: **Free** — يعمل باختيار Docker أو Node؛
   مع Node اجعل Build Command: `npm install` و Start Command: `node server.js`).
3. بعد اكتمال النشر افتح الخدمة › **Environment**: انسخ قيمة `SERVICE_TOKEN`
   (إن أنشأتها يدويًا فأضف `SERVICE_TOKEN` بقيمة سرية تختارها).
4. انسخ رابط الخدمة من أعلى الصفحة (مثل https://school-whatsapp.onrender.com).
5. في الموقع › صفحة واتساب (حساب المطوّر): أدخل الرابط والتوكن › **فحص الاتصال** › **إضافة سيرفر** ثم امسح رمز QR.

- جلسة الواتساب تُحفظ تلقائيًا في Firebase، فلا تضيع عند إعادة تشغيل Render أو إعادة النشر.
- السيرفر يُبقي نفسه مستيقظًا (ينادي رابطه كل 10 دقائق) حتى تعمل الرسائل المجدولة في وقتها.
- ملف الخطاب (PDF) يُرسم داخل السيرفر بخط عربي مضمَّن — لا يحتاج متصفحًا ولا Chromium.

السيرفر المفعّل فقط هو الذي يرسل الرسائل المجدولة (يتحقق من التوكن في إعدادات الموقع).

## نقاط النهاية (Authorization: Bearer TOKEN)
- GET /status — الحالة ورمز QR
- POST /send — { to, message }
- POST /send-pdf — { to, message, html, fileName }
- POST /run-daily — { date?, force? } إرسال خطابات المعلمين ليوم محدد الآن
- POST /guardian-run — { date, ids? } إشعارات أولياء الأمور (الدفعة التالية أو طلاب محددون)
- POST /send-monthly — { year, month, testTo?, uids? } التقرير الشهري (Word)
- POST /restart · POST /logout
