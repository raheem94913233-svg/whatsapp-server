# سيرفر إشعارات واتساب على Koyeb
1. ارفع هذه الملفات على مستودع جديد في GitHub.
2. في Koyeb: Create Service › GitHub › اختر المستودع.
3. Environment variables: SERVICE_TOKEN = كلمة سرية تختارها، PORT = 8000.
4. Exposed port = 8000 ثم Deploy.
5. انسخ الرابط (xxxx.koyeb.app) وضعه مع كلمة السر في لوحة تحكم المتجر › سيرفرات واتساب › حفظ › اختبار › امسح QR.
